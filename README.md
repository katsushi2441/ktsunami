# Kurage 津波浸水想定マップ (ktsunami)

住所を入れると、その地点が**津波で何メートル浸かる想定か**を返します。

- デモ: https://kurage.exbridge.jp/ktsunami.php/
- 収録: 全国 3,795,197 セル / 35都道府県
- 出典: 国土数値情報「津波浸水想定データ」(A40) 国土交通省
  ＜オープンデータとして利用可（商用利用可・再配信可）＞

## 設計の芯

### 1. ○×ではなく「何メートル」を返す

0.3mと5mでは取るべき行動が違います。前者は2階への垂直避難で足りることがありますが、
後者は建物ごと水没する想定です。深さの区分ごとに行動指針を添えます。

| 深さ | 返す行動指針 |
| --- | --- |
| 0.01〜0.3m未満 | 浅い浸水だが、流れがあると歩行は危険 |
| 0.3〜1m未満 | 床上浸水。徒歩での移動は困難 |
| 1〜2m未満 | 1階の床上まで浸水。2階以上への垂直避難が最低限必要 |
| 2〜5m未満 | 1階は水没。3階以上か高台へ |
| 5m以上 | 2階では足りない。高台・津波避難ビルへ水平避難 |

### 2. 「区域外」「未収録」「内陸」を必ず区別する

**東京都は沿岸があるのに本データに収録されていません。** 黙って「区域外」と返すと
安全だと誤解させます。3つを分けて返します。

| 状況 | 返す内容 |
| --- | --- |
| 収録県で区域外 | 収録している想定区域には含まれていない |
| 未収録県（東京・福井・香川） | 本データに収録されていない。区域外という意味ではない |
| 内陸8県 | 海に面していないため想定は作成されていない |

### 3. データ時点は都道府県ごとに記録する

**整備年度が県ごとに最大6年違います**（愛知=令和4年度、静岡・高知=平成28年度）。
判定結果にその県の時点を併記します。時点が確認できないデータでは判定しません。

### 4. 海抜を併記する

津波では「避難先が今いる場所より高いか」が判断の基準です。国土地理院の標高APIで
海抜を取得し、測定のもと（5mレーザー等）も添えます。

## なぜ PostGIS を使わないか

A40のポリゴンは**約10m四方の軸平行な矩形**グリッドです（愛知県だけで129,834件）。
矩形なので R-tree の矩形判定がそのまま厳密な内外判定になり、ポリゴン演算が要りません。
SQLite だけで足り、Docker も PostgreSQL も不要です。

## API

```
GET /api/check?q=<住所>
GET /healthz
```

## 技術メモ

- 整備年度は県ごとに違う。`YEARS` を新しい順に探索し、見つかった年度を時点にする
- `ogr2ogr -dialect SQLite` の `ST_MinX/MaxX/MinY/MaxY` で外接矩形だけ取り出す
- `.cpg` を尊重するため `-lco ENCODING` は指定しない（指定すると二重変換で壊れる）
- 生zipは全国で約1GB。`data/raw` は別ディスクへの symlink にしている
